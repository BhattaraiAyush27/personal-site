
# Personal Website — Design Direction

## Identity
Modern Scholar: calm, editorial, thoughtful,
technical, and understated.

## Audience
Recruiters, engineering colleagues,
researchers, and readers.

## Design Principles
- Content before decoration.
- Typography establishes hierarchy.
- Use whitespace deliberately.
- Make writing comfortable to read.
- Projects should communicate real work.
- Prefer restrained visual details.
- Every interactive element must work.

## Palette
Background: #F7F4EE
Text: #22252B
Navy: #1F2A44
Teal: #1F5C63
Bronze: #9A6A3A

Adjust interactive colors to satisfy
accessibility contrast requirements.

## Layout
- Editorial homepage.
- Narrow reading column for articles.
- Wider layouts for project case studies.
- Responsive navigation.
- No gratuitous dashboard-style cards.

## Avoid
- Animated gradient blobs.
- Generic startup hero sections.
- Fake metrics and testimonials.
- Repetitive decorative icons.
- Excessive rounded cards.
- Unnecessary newsletter popups.
- Heavy animations and scroll effects.

## Quality
- Keyboard accessible.
- Responsive on mobile.
- Reduced-motion support.
- Readable contrast.
- No dead links or fake interactions.
